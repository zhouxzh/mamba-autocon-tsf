GLD 黄金价格 ACF 结构分析结果
关键发现
1. 原始价格 ACF：近单位根，对 AutoCon 有毒

序列	ACF[1]	Max|ACF|	显著 lag 数
原始价格	0.9988	0.9988	500/500
对数收益率	-0.0202	0.0594	28/500
|对数收益率|	0.1155	0.1765	160/500
原始价格 ACF 极高是因为趋势（单位根）造成的虚假自相关，不是周期性。用原始价格计算 AutoCon 的全局自相关会导致所有窗口对都成为"正对"——AutoCon 的区分能力完全失效。

2. 收益率 ACF：接近白噪声

对数收益率 ACF 最大值仅 0.059，极弱——说明价格层面几乎没有线性可预测的周期性结构，这与 ETTh2（强年度周期）和 Electricity（强年度周期）数据完全不同。

3. 波动率聚集是最强的可预测模式

|收益率| 的 ACF 有 160 个显著 lag，Ljung-Box 检验 p≈0（极显著 ARCH 效应）。这才是黄金数据中真正有规律的结构。

4. 收益率分布：肥尾

超额峰度 5.86（正态分布=0），左偏 -0.34，MSE 损失在这类数据上会被极端事件过度惩罚。

5. FFT 周期分析

对数收益率的 FFT 没有发现任何清晰的主导周期（所有振幅约 0.0006，均匀分布）——进一步确认黄金价格缺乏 ETT/Electricity 那种年度周期性。

对 AutoCon 适用性的结论

ETTh2 / Electricity  →  强年度周期 → AutoCon 效果极好 (+34%, +11%)
Weather              →  中等周期   → AutoCon 效果一般 (+3%)
GLD 原始价格         →  单位根趋势 → AutoCon 正负对失效，需要修改
GLD 对数收益率       →  近白噪声   → AutoCon 标准实现收益有限
GLD |收益率|         →  ARCH效应   → 用于增强信号是可行方向
直接优化行动清单（按优先级）
最高优先级：修改 init_AutoCon() 中的 ACF 计算，改为对差分/去趋势后的序列计算，避免虚假自相关
高优先级：降低 AutoCon_lambda 从 1.0 → 0.01~0.1（因为 outer-window ACF 信号弱）
高优先级：将 |收益率| 作为额外通道输入（M 模式），利用波动率聚集信号
中优先级：将 MSE 损失替换为 Huber/MAE（因肥尾分布，kurtosis=5.86）
中优先级：使用 ReVIN 归一化（应对价格序列的强趋势）
